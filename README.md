# City Data API Integration

## Overview

This project demonstrates asynchronous data retrieval from external APIs using JavaScript.

It integrates with:

- GeoDB Cities API
- Weatherbit API

The system retrieves city information such as population and elevation, and also fetches real-time weather data.

## Features

- Retrieve city population and elevation
- Retrieve real-time weather data
- Async/await API integration
- Error handling
- External API data ingestion

## Tech Stack

- JavaScript
- Node.js
- REST APIs
- Async Programming
